# ABC Tech ITSM - Intelligent Incident Management & RFC Risk Prediction

An end-to-end Machine Learning project that predicts IT service incident priority and Request for Change (RFC) risk to help IT support teams improve response time and decision making.

## Project Overview

ABC Tech is an IT Service Management (ITSM) company that receives thousands of incidents and change requests. This project builds predictive models to automate:

- Incident Priority Prediction
- RFC Risk Classification
- Data analysis & visualization
- Model comparison and evaluation

## Features

- Data cleaning & preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Multiple ML model training
- Hyperparameter tuning
- Performance evaluation
- Model serialization

## Tech Stack

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- XGBoost
- SQLAlchemy

## Machine Learning Models

- Decision Tree
- Random Forest
- Logistic Regression
- XGBoost
